# Accessibility (a11y) Guide & Specifications

`react-modern-image-cropper` is designed with web accessibility standards in mind. This document outlines the screen reader attributes, keyboard controls, focus state handling, and guides on how developers can customize them.

---

## ⌨️ Keyboard Accessibility

Global keyboard shortcuts are enabled automatically when the editor contains loaded media. Focus-trapping and form-field protection are built-in: typing inside an input, textarea, or content-editable element will automatically suspend shortcuts to prevent accidental inputs.

| Key | Target | Action |
| :--- | :--- | :--- |
| `Arrow Keys` | Crop Frame | Nudges the crop frame position by 0.5% steps |
| `Shift + Arrow Keys` | Crop Frame | Nudges the crop frame position by larger 2% steps |
| `[` / `]` | Canvas | Rotates the image or video by -1° / +1° |
| `R` / `r` | Canvas | Rotates the image/video by 90° clockwise |
| `H` / `h` | Canvas | Flips the media horizontally |
| `V` / `v` | Canvas | Flips the media vertically |
| `+` / `-` | Canvas | Zooms in / out by 10% |
| `0` | Editor | Resets all edits, filters, and crop frames |
| `Ctrl/Cmd + Z` | Editor | Undo the last action |
| `Ctrl/Cmd + Shift + Z` | Editor | Redo the last undone action |

## 🗣️ Screen Reader & ARIA Attributes

All interactive stages and overlays use semantic HTML and correct ARIA landmark roles.

### 1. Interactive Stage
* **Crop Area:** Renders with `role="application"` and an `aria-label` describing its purpose and nudge keyboard shortcuts.
* **Crop Handles:** Each corner and edge handle renders with `role="button"` and a specialized label like `aria-label="Resize crop from top-left corner"`.
* **Focus States:** Handles use CSS `:focus-visible` to highlight with a glow ring (`focus-visible:ring-brand-400`) and scale up slightly when focused.

### 2. Editor Controls & Sliders
* **Header Action Buttons:** (Undo, Redo, Reset, Theme Toggle, paste buttons) use the `title` text for `aria-label` attributes dynamically.
* **Sliders:** Pro adjustments (Brightness, Highlight, Saturation, etc.) render custom slider tracks with correct `aria-label` corresponding to their labels.
* **Video Control Bar:** Renders with play/pause triggers and scrubber tracks carrying correct playback control descriptions.

---

## 🎨 High Contrast & Theming

* **Dark & Light Modes:** Fully integrated and screen-reader independent. Themes can be toggled using `useCropStore().toggleTheme()` or the header toggle button.
* **Color Contrast:** Interactive handles use high-contrast white borders (`border-2 border-white`) combined with deep gradient fills to remain clearly visible over bright, dark, or busy image backgrounds.
* **Visual Grid:** The rules-of-thirds grid is drawn in a high-contrast white with `opacity-40` overlay to ensure visual alignment aid for users with low vision.
